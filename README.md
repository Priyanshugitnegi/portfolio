## 💻 Run Locally

### Prerequisites
- Node.js and npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Priyanshugitnegi/portfolio.git
   ```

2. Navigate into the project directory:

   ```bash
   cd portfolio
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
